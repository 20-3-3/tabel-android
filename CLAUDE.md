# «Табель» для Android — памятка для Claude

Главная памятка проекта (правила владельца, устройство кода, история версий, открытые вопросы) лежит в iOS-репозитории:
`20-3-3/work-calendar` → `CLAUDE.md`. Прочитай её в первую очередь.

## Главное про этот репозиторий
- Android-версия трогается **только** когда владелец прямо сказал «для Android». Обычные правки идут в iOS.
- Это та же программа, что и iOS v22, плюс:
  - `manifest.webmanifest` — установка из Chrome («Установить приложение»);
  - `sw.js` — офлайн-кэш: свои файлы «сначала сеть», чужие (шрифты, Excel, распознавание) «сначала кэш»; запросы `?check=` (проверка обновлений) идут мимо кэша. При каждом выпуске менять имя кэша `CACHE`. Все имена кэшей начинаются с `tabel-`, и при обновлении удаляются только они: на том же сайте `20-3-3.github.io` живёт iOS-версия. Чужие файлы сохраняются только при удачном ответе (запрос в режиме cors);
  - регистрация `sw.js` в `index.html` сразу после `loadState();`;
  - иконки `icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — вариант №5 «неоновый календарь»;
  - тексты про Safari и iPhone заменены на Chrome и телефон.
- `APP_BUILD` начинается с `Android · …`.
- Перенос новой iOS-версии сюда: взять iOS `index.html`, повторить правки из списка выше, проверить установку (CDP `Page.getInstallabilityErrors`), работу без сети, обновление и скорость.
